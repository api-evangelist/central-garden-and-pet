Central Garden & Pet Company (Nasdaq: CENT, CENTA) is a Walnut Creek, California manufacturer and distributor of branded pet supplies and lawn & garden products — Nylabone, Kaytee, Aqueon, Four Paws, Farnam, Pennington, Amdro, Sevin and Ferry-Morse among roughly seventy brands — with its own nationwide pet and garden distribution network. It is a consumer-products company, not a software company: it publishes no developer portal, public API, SDK, package, OpenAPI, AsyncAPI, GraphQL, MCP server, A2A agent card or llms.txt, and retailer and distributor connectivity is EDI through E2open under private contract. The host developer.central.com once recorded here does not resolve, and api.central.com, on Central's own network block, serves only a 2015-era IIS placeholder page, so no API entry is carried. On the horizontal regulatory layer its privacy notice states the Global Privacy Control signal is honored and links a OneTrust portal for CCPA and GDPR data subject requests.
